
# CreatureCollector

A C# creature-collecting RPG prototype developed during my 20-week internship at Buss-IT-Labs.

## About the Project

CreatureCollector is a console-based RPG prototype featuring exploration, creature encounters, battles, and collection mechanics.

The project was created to practice implementing interconnected gameplay systems using object-oriented programming.

## Features

- Explore different locations
- Encounter enemy creatures
- Participate in battles
- Attempt to capture creatures
- Manage inventory items
- Earn rewards
- Save and load game progress

## Technologies

- C#
- .NET 10
- Console Application
- Object-Oriented Programming
- Random Encounters
- Collections
- Data Serialization

## Getting Started

### Requirements

- .NET 10 SDK

### Run the Application

Open the project in Visual Studio or navigate to the directory containing the `.csproj` file and execute:

```bash
dotnet run
```
